# Shopping List App

A simple and intuitive shopping list application for Android, built with Kotlin and Jetpack Compose. The app allows users to create, manage, and track their shopping lists efficiently. It also integrates with an external weather API to provide real-time weather updates.

## Features

1. **Shopping List Creation** – Users can create multiple shopping lists.
2. **Item Management** – Each list contains items with checkboxes to mark completed purchases.
3. **List Deletion & Trash Bin** – Lists can be moved to a trash bin before permanent deletion.
4. **Theming Support** – The app provides a UI with light and dark themes.
5. **Weather Integration** – Displays real-time weather information using an external API.

## Tech Stack

- **Platform:** Android  
- **Programming Language:** Kotlin  
- **Database:** Firebase Realtime Database  
- **UI Framework:** Jetpack Compose  
- **Cloud Services:** Firebase  
- **External API:** Weather API integration  

## Installation

1. Clone the repository:

```
git clone https://github.com/your-repo/shopping-list-app.git cd shopping-list-app
```

2. Open the project in Android Studio.

3. Ensure you have the latest Kotlin and Compose dependencies installed.

4. Configure Firebase:
- Set up a Firebase project.
- Add the `google-services.json` file to the `app/` directory.
- Enable Realtime Database in Firebase Console.

5. Build and run the project on an emulator or physical device.

## Usage

- **Create Lists**: Tap the "+" button to create a new shopping list.
- **Add Items**: Enter items into a list and check them off when purchased.
- **Delete Lists**: Move lists to the trash bin; permanently delete them if needed.
- **Change Theme**: Toggle between light and dark themes in the settings.
- **View Weather**: The app fetches and displays real-time weather data.
